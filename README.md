# ChromeOS, Google Admin Console and MS Intune

### Chrome Admin Console and Google Admin Console are very similar to MS EntraID and Intune. Same idea: centralized control with a dashboard. 
### To be fair, EntraID is an IAM, whereas the others are not. 

## Chrome Admin Console
A centralized platform (like Cove or CIPP) that lets admin config, manage and moniter a fleet of chromebooks

You can remotely manage thousands of devices! This includes tracking, disabling lost devices, enrolling new ones, deprovisioning old ones

Policy reinforcement

App management, including blocking and force-install

Automated updates

## Google App Management 

We use the Google Admin Console for Google App Management. Google Workspace. 
You login over at admin.google.com

There is a menu on the left of the main dashboard that lets you manage Users, Groups, OUs, Apps, Security. It's all there
